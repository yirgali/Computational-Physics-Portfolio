# Computational-Physics-Portfolio# Computational Physics & Hardware Portfolio

A collection of numerical physics simulations, differential equation models, and embedded hardware measurement setups developed using **Python (`NumPy`, `SciPy`, `Matplotlib`)** and **C++ (`Arduino`)**.

---

## 📂 Projects Overview

| Project | Domain | Tools & Methods | Description |
| :--- | :--- | :--- | :--- |
| **[Maxwell-Boltzmann Distribution](./Maxwell-Boltzmann-Distribution)** | Statistical Mechanics | `Python`, `NumPy`, `SciPy (KDE)`, `Matplotlib` | 2D hard-sphere molecular dynamics simulation demonstrating velocity thermalization and convergence to the theoretical Maxwell-Boltzmann distribution. |
| **[Optical Stroboscope & Tachometer](./Optical-Stroboscope)** | Optics & Embedded Systems | `Arduino`, `C++`, `PWM`, `Harmonic Analysis` | Non-contact optical RPM measurement (~4,100 RPM) using microsecond LED flash timing (`micros()`) and harmonic frequency filtering. |
| **[Coupled Spring-Mass Collision](./springCollision)** | Classical Mechanics / ODEs | `Python`, `SciPy (solve_ivp)`, `Curve Fitting` | Analytical center-of-mass derivation and numerical ODE integration of a two-body spring collision system. |
| **[Electric Potential Landscape](./Electric-Potential-Landscape)** | Electromagnetism | `Python`, `NumPy`, `Matplotlib`, `Jupyter` | Numerical computation and 2D/3D visualization of electrostatic potential fields generated by point-charge and dipole configurations. |
| **[N-Body Gravitational Simulation](./N-Body%20Simulation)** | Orbital Mechanics | `Python`, `NumPy`, `Matplotlib`, `Jupyter` | Multi-body gravitational trajectory integration for planetary/solar system dynamics. |
| **[Galaxy Collision Simulation](./Galaxy%20Collision)** | Astrophysics / N-Body | `Python`, `NumPy`, `Matplotlib`, `Jupyter` | Gravitational interaction and tidal tail formation during galactic encounters. |
| **[2D Elastic Collision](./2DCollision)** | Kinematics | `Python`, `NumPy`, `Matplotlib` | Vector momentum and kinetic energy conservation in 2D multi-particle elastic collisions. |
| **[1D Elastic Collision](./1D-collision)** | Kinematics | `Python`, `NumPy`, `Matplotlib` | Impulse, momentum transfer, and velocity tracking for 1D elastic collisions. |

---

## 🛠️ Tech Stack
* **Languages:** Python, C/C++ (Arduino)
* **Scientific Libraries:** NumPy, SciPy (`solve_ivp`, `curve_fit`, `gaussian_kde`), Matplotlib, Pandas, SymPy
* **Hardware & Prototyping:** Arduino, BJT Switching Circuits, PWM Motor Control, Optical Sensing
